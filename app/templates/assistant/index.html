How Zia works

1. Scoped data. Zia only queries records you are allowed to see. Employees never see another employee's restricted data.

2. Real numbers. Figures are computed by the same services the dashboard uses - SQL aggregations and pandas.

3. Honest AI. {% if llm_configured %} An AI provider is configured, so it words the answer using the verified numbers. If the call fails, Zia says so and falls back to plain text. {% else %} No AI provider is configured, so Zia answers with the built-in deterministic engine. To enable AI wording, set ZIA_LLM_API_KEY in your .env file and restart the app. {% endif %}
